# Commands Plus Python Plugin

This plugin adds a few fun/useful vanilla friendly commands to your bds!

## Featured Commands:

- /offhand -> puts whatever is in your mainhand in your offhand
- /hat -> puts whatever is in your mainhand on your head (Actions & Stuff makes blocks visible on your head!)
- /motd -> allows you to view the current motd (you can set this in the plugin's config)
- /nick -> allows players to give themselves custom display names
